# Check list and pass criteria
| # | Check | Pass |
| --- | --- | --- |
| 1 | Title present, 30-60 chars, unique per page | yes |
| 2 | Meta description 70-160 chars | yes |
| 3 | Canonical present and self-referencing (or intentional) | yes |
| 4 | hreflang set complete and reciprocal; matches translated_slugs | yes |
| 5 | Exactly one h1 | yes |
| 6 | Heading levels do not skip | yes |
| 7 | Landmarks header/nav/main/footer present | yes |
| 8 | JSON-LD parses; types valid for page kind | yes |
| 9 | robots.txt reachable; no accidental disallow of assets | yes |
| 10 | sitemap.xml present, lastmod within 30 days for changing pages | yes |
| 11 | Preview routes noindex | yes |
| 12 | Internal links >= 3 per page; no orphans in crawl set | yes |
| 13 | No broken internal links | yes |
| 14 | Alt text on all content images; decorative images alt="" | yes |
| 15 | Width/height on images (CLS) | yes |
| 16 | Modern formats (WebP/AVIF) via srcset | yes |
| 17 | Lazy loading not applied to LCP image | yes |
| 18 | Render-blocking scripts = 0 in head | yes |
| 19 | Third-party scripts <= 5 | yes |
| 20 | Fonts preloaded or `font-display: swap` | yes |
| 21 | Viewport meta with viewport-fit=cover when full-bleed | yes |
| 22 | Breadcrumb markup where breadcrumbs shown | yes |
| 23 | Dated content and author identity on articles | yes |
| 24 | Question-shaped headings and definitional paragraphs on informational pages | yes |
| 25 | Primary-source outbound links on claims | yes |
| 26 | OG and Twitter card tags | yes |
| 27 | 404 page returns 404 status | yes |
| 28 | Redirect chains <= 1 hop | yes |
| 29 | HTTPS everywhere; no mixed content | yes |
| 30 | Pagination uses crawlable links | yes |
